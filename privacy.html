Privacy policy

Drive Sync — personal use only. Last updated: 20 October 2026.

  • Drive Sync runs only on my own computer. It has no server and sends no data to anyone except Google Drive.
  • It uses Google Drive access only to upload my own files to my own Google Drive and to read the folder list there.
  • The Google sign-in token is stored only on my computer (optionally encrypted). Passwords are never seen or stored by the program.
  • No data is sold, shared, analysed or used for advertising. There is no tracking.
  • Access can be removed at any time at myaccount.google.com/permissions.

Drive Sync's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

По-русски

  • Drive Sync работает только на моём компьютере. У неё нет сервера, она ничего никуда не отправляет, кроме Google Диска.
  • Доступ к Google Диску используется только для загрузки моих файлов на мой Диск и чтения списка папок на нём.
  • Пропуск входа в Google хранится только на моём компьютере (можно зашифровать). Пароль программа не видит и не хранит.
  • Данные никому не продаются и не передаются, не анализируются и не используются для рекламы. Слежки нет.
  • Доступ можно отозвать в любой момент: myaccount.google.com/permissions.
